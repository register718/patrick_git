# sources/

* `all/<key>.pdf` — canonical library, one file per paper, named by BibTeX key (`_supp` = supplement). 76 files.
* `M0 … M11`, `Mmem`, `general` — copies of the papers cited in that module (same names).
* `INDEX.md` — A–Z table and per-module lists. `_duplicates/` — a second copy of Kamino 2017 that you supplied.
* Still missing: **Nagumo et al. 1962** (https://doi.org/10.1109/jrproc.1962.288235, IEEE paywall).
