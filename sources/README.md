# sources/

* `all/<key>.pdf` — canonical library, one file per paper, named by BibTeX key (`_supp` = supplement). 89 files.
* `M0 … M11`, `Mmem`, `general` — copies of the papers cited in that module (same names).
* `INDEX.md` — A–Z table and per-module lists. `_duplicates/` — second copies that you supplied (Kamino 2017; `elzie2009_2597.pdf`, identical to `all/elzie2009.pdf`).
* Still missing: **Nagumo et al. 1962** (https://doi.org/10.1109/jrproc.1962.288235, IEEE paywall).
